# BridgePath AI Demo

A small interactive demo for the CEN Business Competition concept.

## for those tryna run our site in local enviornment 

Use the virtual environment Python runtime:

```powershell
.\.venv\Scripts\python.exe app.py
```

Then open:

```text
http://127.0.0.1:5000
```

## Included Flow

- Login and logout
- Local sign up with password rules
- Student profile input
- Personalized weekly, monthly, and quarterly roadmap with school, major, and industry logic
- Generated plan summary
- Alumni recommendation cards with match score, match reason, recommended action, and relationship status
- Coffee chat message and question generator with tone, goal, and length controls
- Progress dashboard with readiness score, risk, next best action, progress bars, and skill gap tracker

The alumni profiles are synthetic demo data.
